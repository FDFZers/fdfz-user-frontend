# 社团与活动

> 示例条目：活动时间、招募安排和参与要求请以组织方发布的信息为准。

## 参加前可以确认

- 活动面向哪些年级或成员开放。
- 是否需要报名，以及报名截止时间。
- 活动地点、所需材料和联络方式。
- 临时调整或取消时通过什么渠道通知。

## 活动信息记录模板

| 项目       | 内容           |
| ---------- | -------------- |
| 活动名称   | 示例活动       |
| 组织方     | 示例社团或组织 |
| 时间与地点 | 以正式通知为准 |
| 报名方式   | 以正式通知为准 |
